1. Factory Constructors

Factory Constructor adalah constructor khusus dalam Dart yang digunakan untuk mengontrol pembuatan objek. Factory constructor tidak selalu membuat objek baru, tetapi dapat mengembalikan objek yang sudah ada atau objek dari subclass lain.


class Mahasiswa {
  final String nama;
  final String nim;
  final String kelas;
  final String prodi;

  // Main Constructor
  Mahasiswa({
    required this.nama,
    required this.nim,
    required this.kelas,
    required this.prodi,
  });

  // Redirecting Constructor
  Mahasiswa.defaultData()
      : this(
          nama: 'Marta Saputra',
          nim: '251410020',
          kelas: 'SI2A',
          prodi: 'Sistem Informasi',
        );

  Mahasiswa.namaSaja(String nama)
      : this(
          nama: nama,
          nim: '251410020',
          kelas: 'SI2A',
          prodi: 'Sistem Informasi',
        );

  Mahasiswa.kelasSI2A(String nama, String nim)
      : this(
          nama: nama,
          nim: nim,
          kelas: 'SI2A',
          prodi: 'Sistem Informasi',
        );

  @override
  String toString() {
    return '''
Nama  : $nama
NIM   : $nim
Kelas : $kelas
Prodi : $prodi
''';
  }
}

void main() {
  var mhs1 = Mahasiswa.defaultData();
  var mhs2 = Mahasiswa.namaSaja('Marta Saputra');
  var mhs3 = Mahasiswa.kelasSI2A('Marta Saputra', '251410020');

  print('=== Data Mahasiswa 1 ===');
  print(mhs1);

  print('=== Data Mahasiswa 2 ===');
  print(mhs2);

  print('=== Data Mahasiswa 3 ===');
  print(mhs3);
}

2. Pengantar Redirecting Constructors

Redirecting Constructor adalah constructor yang mengarahkan pemanggilan ke constructor lain dalam class yang sama. Tujuannya untuk mengurangi penulisan kode yang berulang.


import 'dart:math';

class Circle {
  final double radius;

  // Main Constructor
  Circle(this.radius);

  // Redirecting Constructor dari diameter
  Circle.fromDiameter(double diameter)
      : this(diameter / 2);

  // Redirecting Constructor dari keliling
  Circle.fromCircumference(double circumference)
      : this(circumference / (2 * pi));

  // Redirecting Constructor dari luas
  Circle.fromArea(double area)
      : this(sqrt(area / pi));

  double get area => pi * radius * radius;

  double get circumference => 2 * pi * radius;

  @override
  String toString() {
    return '''
Radius      : ${radius.toStringAsFixed(2)}
Luas        : ${area.toStringAsFixed(2)}
Keliling    : ${circumference.toStringAsFixed(2)}
''';
  }
}

void main() {
  print("Nama  : Marta Saputra");
  print("NIM   : 251410020");
  print("Kelas : SI2A\n");

  var c1 = Circle(7);
  var c2 = Circle.fromDiameter(14);
  var c3 = Circle.fromCircumference(44);
  var c4 = Circle.fromArea(154);

  print("=== Circle dari Radius ===");
  print(c1);

  print("=== Circle dari Diameter ===");
  print(c2);

  print("=== Circle dari Keliling ===");
  print(c3);

  print("=== Circle dari Luas ===");
  print(c4);
}

5.Solusi dengan Redirecting Constructors

Redirecting constructor mengatasi duplikasi kode dengan mengarahkan constructor lain ke constructor utama sehingga kode menjadi lebih ringkas, rapi, dan mudah dikelola.


import 'dart:math';

  final double radius;

  // Main Constructor
  Circle(this.radius);

  // Redirecting Constructor dari Diameter
  Circle.fromDiameter(double diameter)
      : this(diameter / 2);

  // Redirecting Constructor dari Keliling
  Circle.fromCircumference(double circumference)
      : this(circumference / (2 * pi));

  Circle.fromArea(double area)

Multiple Redirecting Levels terjadi ketika satu constructor mengarahkan ke constructor lain, lalu constructor tersebut mengarahkan lagi ke constructor berikutnya. Hal ini membantu mengelola banyak pilihan inisialisasi objek secara terstruktur.


class DatabaseConfig {

  final int port;

10. Redirecting Constructors vs Factory Constructors

Redirecting Constructor digunakan untuk menyederhanakan constructor, sedangkan Factory Constructor digunakan untuk mengatur bagaimana objek dibuat dan dikembalikan.


class Person {
  final String name;
  final String nim;
  final String kelas;
  final int age;
  final String? email;

  // Main Constructor
  Person({
    required this.name,
    required this.nim,
    required this.kelas,
    required this.age,
    this.email,
  });

  // Redirecting Constructors
  Person.defaultStudent()
      : this(
          name: "MARTA SAPUTRA",
          nim: "251410020",
          kelas: "SI2A",
          age: 20,
          email: "marta251410020@student.ac.id",
        );

  Person.fromName(String name)
      : this(
          name: name,
          nim: "251410020",
          kelas: "SI2A",
          age: 20,
        );

  Person.student(String name, String nim, String kelas)
      : this(
          name: name,
          nim: nim,

  String toString() {
    return '''
============================
DATA MAHASISWA

Kelas  : $kelas
Umur   : $age
Email  : ${email ?? "Tidak Ada"}
============================
''';
  }
}

11. API Response dengan Redirecting Constructors API Response dengan Redirecting Constructor adalah penggunaan

API Response dengan Redirecting Constructor adalah penggunaan redirecting constructor untuk mempermudah pembuatan objek dari data yang berasal dari API. Constructor tambahan dapat mengarahkan ke constructor utama sehingga proses inisialisasi lebih sederhana dan konsisten.


class ApiResponse {
  final bool success;
  final T? data;
  final String? error;
  final int statusCode;
  final DateTime timestamp;

  // Main Constructor
  ApiResponse({
    required this.success,
    this.data,
    this.error,
    required this.statusCode,
    required this.timestamp,
  });

  // Success Response
  ApiResponse.success(T this.data)
      : this(
          success: true,
          data: data,
          statusCode: 200,
          timestamp: DateTime.now(),
        );

  // Error Response
  ApiResponse.error(String this.error, int statusCode)
      : this(
          success: false,
          error: error,
          statusCode: statusCode,
          timestamp: DateTime.now(),
        );

  // Not Found
  ApiResponse.notFound()
      : this(
          success: false,
          error: "Data tidak ditemukan",
          statusCode: 404,
          timestamp: DateTime.now(),
        );

  @override
  String toString() {
    return '''
=========================
NAMA  : MARTA SAPUTRA
NIM   : 251410020
KELAS : SI2A
=========================
Success    : $success
Data       : $data
Error      : $error
StatusCode : $statusCode
Timestamp  : $timestamp
''';
  }
}

void main() {
  var sukses = ApiResponse.success(
    "Data Mahasiswa MARTA SAPUTRA berhasil dimuat",
  );

  var gagal = ApiResponse.error(
    "Terjadi kesalahan server",
    500,
  );

  var tidakDitemukan = ApiResponse.notFound();

  print("=== SUCCESS RESPONSE ===");
  print(sukses);

  print("=== ERROR RESPONSE ===");
  print(gagal);

  print("=== NOT FOUND RESPONSE ===");
  print(tidakDitemukan);
}

class Product {

13. Best Practices Redirecting Constructor

Gunakan untuk menghindari duplikasi kode Jangan menulis logika yang sama pada banyak constructor. Buat satu constructor utama Jadikan satu constructor sebagai pusat inisialisasi data. Gunakan nama constructor yang jelas Contoh: default(), guest(), admin(), fromApi(). Hindari redirecting yang terlalu banyak Terlalu banyak level redirect dapat membuat kode sulit dipahami. Kombinasikan dengan named parameters Membuat kode lebih mudah dibaca dan fleksibel. Gunakan factory constructor jika membutuhkan logika kompleks Redirecting constructor cocok untuk pengalihan sederhana. Factory constructor lebih cocok jika perlu validasi, caching, atau memilih objek tertentu.


class User {
  final String id;
  final String username;
  final String email;
  final DateTime createdAt;
  final bool isActive;

  // Constructor utama
  User({
    required this.id,
    required this.username,
    required this.email,
    DateTime? createdAt,
    this.isActive = true,
  }) : createdAt = createdAt ?? DateTime.now();

  // Redirecting Constructor Guest
  User.guest()
      : this(
          id: "guest_001",
          username: "Guest",
          email: "guest@example.com",
          isActive: false,
        );

  // Redirecting Constructor Mahasiswa
  User.mahasiswa()
      : this(
          id: "251410020",
          username: "MARTA SAPUTRA",
          email: "251410020@kampus.ac.id",
          isActive: true,
        );

  // Redirecting Constructor dari Username
  User.fromUsername(String username)
      : this(
          id: "user_${username.toLowerCase()}",
          username: username,
          email: "${username.toLowerCase()}@example.com",
        );

  @override
  String toString() {
    return '''
=========================
DATA MAHASISWA
=========================
Nama      : MARTA SAPUTRA
NIM       : 251410020
Kelas     : SI2A
-------------------------
ID User   : $id
Username  : $username
Email     : $email
Aktif     : $isActive
Dibuat    : $createdAt
=========================
''';
  }
}

void main() {
  var guest = User.guest();
  var mahasiswa = User.mahasiswa();
  var custom = User.fromUsername("MartaSaputra");

  print(guest);
  print(mahasiswa);
  print(custom);
}

    print('Diameter    : ${diameter.toStringAsFixed(2)}');
    print('Keliling    : ${circumference.toStringAsFixed(2)}');
    print('Luas        : ${area.toStringAsFixed(2)}');
    print('==============================\n');
  }
}

void main() {
  // Dari radius
  Circle c1 = Circle(7);

  // Dari diameter
  Circle c2 = Circle.fromDiameter(14);

  // Dari keliling
  Circle c3 = Circle.fromCircumference(44);

  // Dari luas
  Circle c4 = Circle.fromArea(154);

  print('CIRCLE DARI RADIUS');
  c1.display();

  print('CIRCLE DARI DIAMETER');
  c2.display();

  print('CIRCLE DARI KELILING');
  c3.display();

  print('CIRCLE DARI LUAS');
  c4.display();
}

15. Kesimpulan

Dari latihan-latihan di atas, dapat disimpulkan bahwa:

    redirecting constructor adalah constructor yang digunakan untuk memanggil constructor lain dalam kelas yang sama dengan sintaks : this(...). Fitur ini membantu mengurangi duplikasi kode, membuat program lebih rapi, dan memusatkan proses inisialisasi objek pada satu constructor utama. Redirecting constructor sangat cocok digunakan untuk membuat constructor alternatif dengan parameter atau nilai default yang berbeda. Namun, redirecting constructor tidak dapat berisi logika yang kompleks karena tidak memiliki body, sehingga untuk kebutuhan validasi atau proses yang lebih rumit sebaiknya menggunakan factory constructor.
